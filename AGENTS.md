# live-speech

Live captioning for local tech talks, built for Thai speech mixed with English technical terms. This `v2` branch is a rewrite from scratch; the 2024 version lives on `main`.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `dtinth/live-speech`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
